# Выбор стека Kanbanity

## Текущая реализация

- **Frontend:** React 18 и TypeScript.
- **Сборка и локальная разработка:** Vite 6.
- **Иконки:** Lucide React.
- **API:** встроенный HTTP-сервер Node.js.
- **База данных:** SQLite через встроенный `node:sqlite` (Node.js 22.13+).

React с TypeScript подходит для интерактивной SPA-доски: компоненты разделяют интерфейс на независимые элементы, а типы помогают проверять структуру задач и колонок. Vite обеспечивает быстрый цикл разработки и компактную production-сборку. HTTP API предоставляет чтение и сохранение состояния; SQLite надёжно хранит его на диске без установки отдельного сервера или нативных npm-пакетов. При первом запуске прежнее состояние из браузера переносится в SQLite.

## Ограничения и дальнейшее развитие

Текущий API хранит единый снимок состояния в таблице `app_state`; это упрощает прототипирование, но уступает нормализованной модели БД с отдельными таблицами пользователей, проектов, колонок, задач и комментариев. Авторизация и разграничение ролей, вложения, миграции схемы, OpenAPI и CI/CD ещё не реализованы. Для совместной работы нескольких пользователей и роста нагрузки следует спроектировать нормализованную схему PostgreSQL, добавить серверную аутентификацию и авторизацию, миграции и отдельный слой контроллеров, сервисов и репозиториев.

Варианты для полного проекта: Vue или Angular для SPA; FastAPI или ASP.NET Core для API; PostgreSQL или SQLite для хранения. Для лабораторного прототипа React/TypeScript/Vite минимизирует инфраструктурные требования, но сам по себе не закрывает серверные требования ТЗ.
